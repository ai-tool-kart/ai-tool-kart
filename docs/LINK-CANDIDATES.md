## Notes for the developer

- **Title weight** is the figure the assistant's guide bar reads (`ASSISTANT.automationMinTitleWeight`, currently 5.2). "Below bar" means the assistant would not show that guide on its own. **Rank score** is what orders the three candidates; the two are different measures, so a lower-ranked candidate can have a higher title weight.
- Search text: story cards use `task`; setups use `title + ". " + description`; roles run each goal in `GOALS_BY_ROLE` separately (top 3 each), pool the results, and keep the three with the highest title weight.
- The link column is `automationPath(niche, slug)`, the route `AutomationDetailPage` serves. A chosen link would be stored as `{ niche, slug }`.
- The roles section links a whole role to one guide. The card actually sends role **and** goal, so a per-goal link (68 goals) would be finer-grained if the client wants that instead.
- The usage stories are illustrative content, not real customers; see the note in `HowPeopleAreUsingAISection.tsx`.
- Generated from the matcher and the imported automation data as of 2026-09-24. Re-running after a new automation import can change the candidates.
