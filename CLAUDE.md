# AI Tool Kart

## Project Goal

AI Tool Kart is a website for discovering and exploring AI tools.

## Current Phase

We are currently implementing an existing Claude Design UI as a production React frontend.

Do NOT build the backend yet unless explicitly instructed.

## Frontend Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Future Backend Stack

- Node.js
- Express
- TypeScript
- PostgreSQL
- Prisma

## Development Rules

1. The existing Claude Design is the visual source of truth.
2. Do not redesign the UI unless explicitly requested.
3. Preserve typography, spacing, colors, borders, radius, layout and interactions from the design.
4. Build reusable React components instead of one giant component.
5. Do not hardcode repeated UI structures unnecessarily.
6. Keep frontend code inside `client/`.
7. Do not introduce Next.js.
8. Do not create backend functionality yet.
9. Do not install unnecessary packages without explaining why.
10. Before making large changes, inspect the existing project first.
11. Keep the application running after changes.
12. Fix TypeScript/build errors before considering a task complete.
